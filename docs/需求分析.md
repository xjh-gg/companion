# 桌面情感陪伴助手 — 需求分析文档

> 项目代号：**Companion**
> 硬件平台：正点原子 DNESP32-S3（ESP32-S3-WROOM-1）
> 作者：徐俊豪
> 日期：2026-10

---

## 1. 项目背景与目标

### 1.1 背景
现代人桌面设备越来越多（电脑、手机、手表），但大多是"工具"——你不操作它就毫无反应。缺少一个**有存在感、会主动回应你**的桌面小伙伴。

### 1.2 目标
做一个放在桌上的小型陪伴设备：
- **感知你**：拿起、摇晃、靠近、按键
- **回应你**：灯效变化、音效、语音对话
- **记得你**：偏好设置掉电不丢，互动日志可查
- **提醒你**：定时休息、环境异常

### 1.3 产品定位
**"AI 大脑 + 传感器身体"**：
- 语音对话/语义理解 → 交给小智 AI 云端（现成固件）
- 传感器感知 + 本地反应 + 状态机 → 自己写代码实现

## 3. 硬件资源清单（板载已有，I2C 扫描实测确认）

| 外设 | 型号/接口 | 地址/引脚 | 在本项目中的作用 |
|---|---|---|---|
| 主控 | ESP32-S3-WROOM-1 | WiFi+BLE | 跑 FreeRTOS、传感器调度、WiFi 联网 |
| 红色 LED | GPIO1 | — | 表达"情绪"：慢闪=平静、快闪=开心、急促=报警 |
| 电源灯 | GPIO2 | — | 上电即亮，不用管 |
| 4 个按键 | KEY0~3（经 XL9555） | XL9555 PORT1 | 交互：问时间/提醒/切换模式 |
| 蜂鸣器 | XL9555 BEEP_IO (bit3) | 0x0008 | 简单提示音（嘀、旋律） |
| 三轴加速度计 | QMA6100P | I2C 0x12 | 检测拿起、摇晃、姿态 |
| 环境光/接近传感器 | AP3216C | I2C 0x1E | 手靠近触发互动、环境亮度判断 |
| IO 扩展芯片 | XL9555 | I2C 0x20 | 扩展按键和蜂鸣器控制脚 |
| EEPROM | AT24C02 | I2C 0x50, 256B | 存用户偏好 |
| 音频 Codec | ES8388 (I2S) | I2C 0x10 | 麦克风输入 + 喇叭输出（M5 语音对话） |
| USB 转串口 | CH340C | UART0 | 日志输出、烧录 |

> **不使用/未确认**：WS2812 RGB（排针引出无板载）、DHT11 单总线（原理图预留未确认贴片）、OV2640 摄像头、SPI LCD、TF 卡座

## 4. 功能需求

### 4.1 感知层（输入）

| 编号 | 功能 | 触发方式 | 说明 |
|---|---|---|---|
| F1 | 拿起检测 | QMA6100P 加速度 | 检测到姿态变化/加速度峰值 |
| F2 | 摇晃检测 | QMA6100P | 短时间内多次方向变化 |
| F3 | 手靠近检测 | AP3216C 接近通道 | 手伸到传感器前方 < 5cm |
| F4 | 按键交互 | KEY0~3 | 4 个键对应不同指令 |
| F5 | 光照采集 | AP3216C 光照通道 | 记录环境明暗（仅记录日志，不参与报警判定） |
| F6 | 语音输入 | ES8388 麦克风 | 唤醒词 + 语音对话（小智） |

### 4.2 决策层（状态机）

设备有以下"心情状态"，根据输入自动切换：

| 状态 | 进入条件 | 红灯表现 |
|---|---|---|
| **待机（呼吸）** | 无操作 30 秒以上 | 慢闪（2 秒一次） |
| **被关注（开心）** | 拿起 / 手靠近 / 按键 | 快闪（0.2 秒一次） |
| **互动中** | 正在语音对话 | 跟随声音节奏闪烁 |
| **犯困（提醒休息）** | 定时到（默认 60 分钟） | 慢闪变快 + 蜂鸣器轻响 |
| **报警（环境异常）** | 长时间无互动 | 急促闪 + 蜂鸣器连响 |

> 说明：环境光过暗（ALS）自方案 C 起**仅作环境信息记录**，由 `sensor_task` 去抖后打印日志，不触发 STATE_ALARM，也不改变状态、LED 或蜂鸣器。判定参数：进入阈值 50、恢复阈值 60、连续 3 次采样确认（采样周期约 50ms）；恢复阈值 60 为初始值，尚待实测标定。

### 4.3 反馈层（输出）

| 编号 | 功能 | 实现方式 |
|---|---|---|
| F7 | 情绪灯效 | GPIO1 红灯：不同闪烁频率对应不同心情 |
| F8 | 提示音效 | 蜂鸣器：简单旋律（短嘀、双嘀、三声） |
| F9 | 语音对话 | ES8388 喇叭播放小智返回的语音 |
| F10 | 状态日志 | 串口打印事件日志 |

### 4.4 记忆与存储

| 编号 | 功能 | 实现方式 |
|---|---|---|
| F11 | 偏好存储 | AT24C02 存：音量、提醒间隔、模式开关 |
| F12 | 对话记忆 | 交给小智云端（本地不存对话记录） |

## 5. 非功能需求

| 项 | 要求 |
|---|---|
| 实时性 | 传感器响应 < 100ms，中断不阻塞主循环 |
| 功耗 | 待机模式下 LED 低亮度，WiFi 可按需开关 |
| 可靠性 | I2C 读取失败重试 3 次，EEPROM 写入校验 |
| 代码结构 | BSP 模块化分层（components/BSP/xxx） |
| 可维护性 | 每个模块 .c/.h 分离，函数注释清晰 |

## 7. 开发里程碑

| 阶段 | 内容 | 产出 |
|---|---|---|
| **M1 基础驱动** | I2C + XL9555 + LED + QMA6100P + AP3216C | 能读传感器、控制灯效和蜂鸣器 |
| **M2 状态机** | 实现 5 个心情状态切换 + 定时提醒 | 设备有"情绪"了 |
| **M3 存储** | AT24C02 偏好存取 | 掉电不丢 |
| **M4 联网** | WiFi + MQTT 数据上报 | 联网能力 |
| **M5 语音** | 集成小智固件，麦克风对话 | 能说话能回答 |

> **当前实现说明**：XiaoZhi 2.0.3 交付固件**未实现**传感器/按键的 MQTT 自定义上报；MQTT 仅承载 XiaoZhi 语音控制与 MCP。详见 `docs/MQTT_CLOUD_AI_AUDIT.md`。

## 8. 面试亮点（简历话术）

> 基于 ESP32-S3 设计实现了一个桌面情感陪伴助手，采用"AI 云端 + 传感器本地"分层架构：
> - 自研多传感器驱动（I2C 加速度计/光照/IO扩展/EEPROM、I2S 音频 codec）
> - 状态机实现 5 种情绪状态自动切换，事件响应 < 100ms
> - FreeRTOS 多任务调度：传感器采集、状态机、日志并行运行
> - 本地 EEPROM 存用户偏好，WiFi 云端负责语音对话
> - 模块化 BSP 分层设计，代码可复用、可测试

## 9. 风险与备注

| 风险 | 应对 |
|---|---|
| ES8388 I2S 音频驱动复杂 | M5 阶段再做，先做蜂鸣器音效 |
| 小智源码集成难度 | 先验证小智固件能跑，再研究接口 |
| AT24C02 只有 256B | 只存核心偏好 |
| 手靠近检测灵敏度 | AP3216C 接近阈值可软件调 |
