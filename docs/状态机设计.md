# 状态机设计

> **历史设计说明**：当前 XiaoZhi 交付实现中，ALS 暗光仅记录、不触发报警；`STATE_ALARM` 当前没有事件生产者，不可达。当前实现以 `docs/phase2_acceptance_20261022/PHASE2_FINAL_ACCEPTANCE_REPORT.md` 为准。

## 5 种心情状态

```
                    ┌──────────┐
          ┌────────►│  待机    │◄────────┐
          │         │ 慢闪     │         │
          │         └────┬─────┘         │
          │              │               │
   30s无操作│        拿起/靠近/按键        │
          │              ▼               │
          │         ┌──────────┐         │
          │         │ 被关注   │         │
          │         │ 快闪     │         │
          │         └────┬─────┘         │
          │              │               │
          │         语音对话中            │
          │              ▼               │
          │         ┌──────────┐         │
          │         │ 互动中   │         │
          │         │ 随声闪烁  │         │
          │         └────┬─────┘         │
          │              │               │
          │         对话结束              │
          │              │               │
          │         ┌────▼─────┐         │
          │         │ 犯困     │─────────┘

          │              │

                    │ 急促闪    │
```

## 状态迁移表

| 当前状态 | 事件 | 下一个状态 | LED 表现 |
|---|---|---|---|
| 待机 | 拿起/摇晃/手靠近/按键 | 被关注 | 快闪 0.2s |
| 待机 | 60分钟到 | 犯困 | 变慢闪+蜂鸣器 |
| 待机 | 光照过暗 | 报警 | 急促闪 |
| 被关注 | 开始语音对话 | 互动中 | 随声节奏 |
| 被关注 | 30s 无操作 | 待机 | 慢闪 2s |
| 互动中 | 对话结束 | 被关注 | 快闪 |
| 犯困 | 用户按键确认 | 待机 | 慢闪 |
| 报警 | 用户按键确认 | 待机 | 慢闪 |
| 任意状态 | 紧急报警 | 报警 | 急促闪+蜂鸣器 |

## 状态变量
```c
typedef enum {
    STATE_IDLE = 0,      // 待机
    STATE_HAPPY,         // 被关注
    STATE_INTERACT,      // 互动中
    STATE_SLEEPY,        // 犯困
    STATE_ALARM,         // 报警
} companion_state_t;

companion_state_t current_state = STATE_IDLE;
```
