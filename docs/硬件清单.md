# Companion 陪伴助手 - 硬件清单与引脚分配

> 基于正点原子 DNESP32-S3 开发板（原理图 V1.4 + I2C 总线扫描实测确认）

## 一、核心主控

| 项目 | 规格 |
|---|---|
| 主控芯片 | ESP32-S3-WROOM-1 |
| 内核 | Xtensa LX7 双核 240MHz |
| Flash | 8MB |
| PSRAM | 8MB |
| 调试串口 | CH340C（UART0） |

## 二、I2C 总线设备（SDA=GPIO41, SCL=GPIO42, 400kHz）

| 7位地址 | 芯片 | 功能 | 我们用它做什么 |
|---|---|---|---|
| **0x10** | ES8388 | 音频 codec（麦克风输入 + 喇叭输出） | M5 阶段语音对话 |
| **0x12** | QMA6100P | 三轴加速度计 | 检测拿起/摇晃/放下 |
| **0x1E** | AP3216C | 光照传感器 + 接近检测 | 检测手靠近、环境亮度 |
| **0x20** | XL9555 | 16位 IO 扩展芯片 | 扩展按键、蜂鸣器控制脚 |
| **0x50** | AT24C02 | EEPROM 256字节 | 存储用户偏好/记忆数据 |

## 三、XL9555 IO 分配（地址 0x20）

XL9555 扩展了 16 个 IO，PORT0（低8位）和 PORT1（高8位）：

### PORT0（bit 0~7）
| 位 | 宏定义 | 连接 | 方向 | 说明 |
|---|---|---|---|---|
| bit0 | AP_INT_IO | AP3216C 中断 | 输入 | 接近检测中断 |
| bit1 | QMA_INT_IO | QMA6100P 中断 | 输入 | 加速度变化中断 |
| bit2 | SPK_EN_IO | 喇叭使能 | 输出 | 高电平开喇叭 |
| bit3 | BEEP_IO | 蜂鸣器 | 输出 | 提示音/报警声 |
| bit4 | OV_PWDN_IO | 摄像头掉电 | 输出 | 本项目不用 |
| bit5 | OV_RESET_IO | 摄像头复位 | 输出 | 本项目不用 |
| bit6 | GBC_LED_IO | RGB 灯 | 输出 | 本项目不用 |
| bit7 | GBC_KEY_IO | 光敏感应 | 输入 | 本项目不用 |

### PORT1（bit 8~15）
| 位 | 宏定义 | 连接 | 方向 | 说明 |
|---|---|---|---|---|
| bit8 | LCD_BL_IO | LCD 背光 | 输出 | 本项目不用 |
| bit9 | CT_RST_IO | 电容触摸复位 | 输出 | 本项目不用 |
| bit10 | SLCD_RST_IO | SPI LCD 复位 | 输出 | 本项目不用 |
| bit11 | SLCD_PWR_IO | SPI LCD 电源 | 输出 | 本项目不用 |
| bit12 | KEY3_IO | 按键3 | 输入 | 用户交互按键 |
| bit13 | KEY2_IO | 按键2 | 输入 | 用户交互按键 |
| bit14 | KEY1_IO | 按键1 | 输入 | 用户交互按键 |
| bit15 | KEY0_IO | 按键0 | 输入 | 用户交互按键 |

## 四、直接连接 ESP32-S3 的引脚

| 引脚 | 连接 | 说明 |
|---|---|---|
| GPIO1 | 红色 LED | 板载指示灯（情绪灯效） |
| GPIO2 | 电源指示灯 | 上电即亮 |
| GPIO0 | BOOT 按键 | 下载模式触发 |
| GPIO40 | XL9555 INT | IO 扩展中断输入 |
| GPIO41 | I2C SDA | I2C 数据线 |
| GPIO42 | I2C SCL | I2C 时钟线 |
| GPIO43 | UART0 TX | CH340 串口输出 |
| GPIO44 | UART0 RX | CH340 串口输入 |

## 五、本项目用到的硬件模块

### M1（基础驱动）
- [x] I2C 总线（GPIO41/42）
- [ ] LED 灯效（GPIO1）
- [ ] XL9555 驱动（按键读取 + 蜂鸣器控制）
- [ ] QMA6100P 加速度计（读 X/Y/Z）
- [ ] AP3216C 光照/接近

### M2（状态机）
- 基于传感器数据切换 5 种心情状态
- LED 闪烁频率对应不同状态

### M3（存储）
- AT24C02 EEPROM 存用户偏好

### M4（联网）
- WiFi + MQTT（数据上报）

### M5（语音 AI）
- ES8388 + 麦克风 → 小智 AI 云端对话
- 喇叭播放回复语音

## 六、不用的硬件
- OV2640 摄像头（排针引出，未贴）
- SPI LCD（排针引出）
- TF 卡座
- DHT11/DS18B20 单总线（原理图预留，未确认贴片）
- WS2812 RGB（排针引出，无板载）
